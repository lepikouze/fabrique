Fabrique is installed in the "{{ .Release.Namespace }}" namespace.

1. Setup code (shown once, at the first start):

   kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "fabrique.fullname" . }}-dashboard | grep "setup code"

2. Open the dashboard:
{{- if .Values.ingress.enabled }}

   {{ include "fabrique.publicUrl" . }}
{{- else }}

   kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "fabrique.fullname" . }} 8080:{{ .Values.service.port }}
   then http://localhost:8080
{{- end }}

3. Enter the code, create the administrator account, then follow the Setup page (a model, a Git provider, a first repo).
{{- if .Values.runner.enabled }}
   The built-in runner "{{ .Values.runner.name }}" registers itself: it shows as online under Runners within a minute.
{{- end }}
{{- if not .Values.secrets.existingSecret }}

The application's secrets are in the Secret "{{ include "fabrique.fullname" . }}". Back it up: without it, the model
keys and the Git tokens stored in the dashboard are unreadable. `helm uninstall` does not delete it.
{{- end }}
